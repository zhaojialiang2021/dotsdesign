# MediaNote 回答流笔记

> status: draft
> last_updated: 2026-08-07
> Figma 参考：`7月方案` 节点 `1838:56640`、`2045:27831`、`2045:27887`。

MediaNote 是插入 AI response 正文内容流的笔记卡组件。它用封面、标题、作者与点赞量承接回答中的社区内容；视频笔记额外显示播放标识。

## Harness 定义

- 语义：展示与相邻回答相关的社区笔记，不替代普通图片或视频播放器。
- 生成规则：单篇和两篇使用同一大卡尺寸；三篇及以上切换三列紧凑卡；最多展示前三篇。
- 验证方式：检查 3:4 比例、6px 间距、16px 圆角、两档内容规格和溢出入口。

文档实时预览沿用 ProcessIndicator 的扁平页面结构，四种布局直接铺开，不使用折叠列表或属性控制卡。

## Props

```tsx
<DotsMediaNote
  notes={[{ cover, coverAlt, title, author, avatar, likes, mediaType: 'image | video' }]}
  onNoteClick={openNote}
  onMoreClick={openNotes}
/>
```

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `notes` | `DotsMediaNoteItem[]` | 是 | 按相关性顺序传入；空数组不渲染。 |
| `onNoteClick` | `(note, index) => void` | 否 | 打开对应笔记。 |
| `onMoreClick` | `() => void` | 否 | 超过三篇时打开完整笔记列表。 |

## 布局

| 场景 | 规格 |
|------|------|
| 单篇 | 161.5 × 215.333px，左对齐 |
| 两篇 | 每张 161.5 × 215.333px |
| 三篇 | 三列撑满 329px，每张 105.667 × 140.889px |
| 卡片 | 3:4，间距 6px，圆角 16px，封面 `object-fit: cover` |
| 溢出 | 展示前三篇，卡组下方 12px 展示 44px 高更多入口 |

大卡内容水平留白 12px、底部 12px、内部间距 6px；标题 14/20 medium，作者与点赞 12/18。三列卡水平留白 10px、底部 10px、内部间距 4px；标题 12/18 medium，只展示 14px 作者头像与 10/14 点赞量，不展示用户名。

内容区覆盖 0%-100% 的线性渐变，顶部和底部的 RGB 均使用同一个封面算色结果，顶部 alpha 为 0、底部 alpha 为 1。算色截取图片底部 25% 区域，采用 Color Thief RGB MMCQ 的采样与主色量化逻辑；每 10 个像素采样一次，忽略 alpha 小于 125 的透明像素和 RGB 均大于 250 的近白像素。主色由 RGB 转为 HSB，保持 H、S 不变并降低 B：B≥80 时减 40，20≤B<80 时减 20，B<20 时归零，再转回 RGB。跨域或 Canvas 读取失败时回退 `Always Media Overlay`。

背景模糊使用同方向线性遮罩渐进出现，避免内容区顶部形成水平分界。遮罩在内容区 78% 位置达到完整强度，大卡和三列卡的最大模糊均为 20px，保证底部文字区域有足够对比度。标题最多两行；大卡作者名和点赞量单行截断。标题、作者、点赞文字、头像和点赞图标统一使用 `Shadow Media Note Text` 投影；作者头像另带 0.5px Always White 描边。视频笔记右上角展示 20px 播放标识。

更多入口固定高 44px、圆角 40px，背景为 `Bg 0 Lighter`，文案为「N 篇相关笔记」。

## 交互与触觉

- 点击卡片打开对应笔记，触觉反馈 `light`。
- 笔记卡点击时保持原尺寸，不使用缩小反馈。
- 点击更多入口打开完整笔记列表，触觉反馈 `light`。
- 图片不可拖动；按钮保留清晰的无障碍名称。

## 验收清单

- [ ] 单篇与两篇使用相同的 161.5 × 215.333px 单卡尺寸。
- [ ] 三篇横向撑满 329px，所有卡片比例 3:4。
- [ ] 间距 6px、圆角 16px。
- [ ] 大卡和紧凑卡使用对应字号、头像和留白；紧凑卡不展示用户名。
- [ ] 视频笔记显示右上角播放标识。
- [ ] 渐变底色来自封面底部 25% 区域的 MMCQ 主色，并按 HSB 亮度规则降调。
- [ ] 算色失败时回退 `Always Media Overlay`，不影响卡片内容可读性。
- [ ] 超过三篇只展示前三篇，并出现「N 篇相关笔记」入口。
