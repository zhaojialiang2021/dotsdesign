# MediaImage 回答流图片

> status: draft
> last_updated: 2026-07-30
> Figma 参考：`7月方案` 节点 `2045:27949`、`2045:27660`、`2045:27478`、`2045:29430`。

MediaImage 是插入 AI response 正文内容流的图片媒体组件。它只负责图片展示和更多图片入口，不承担来源卡、笔记卡或视频播放语义。

## Harness 定义

- 语义：用图片补充相邻文字内容，图片必须处在正文段落或标题的承接关系中。
- 生成规则：先读取图片总数；单图再读取原始方向，多图统一裁切为 3:4。
- 验证方式：检查单图尺寸、多图列宽、最多三张、6px 间距、16px 圆角和更多图片入口。

文档实时预览沿用 ProcessIndicator 的扁平页面节奏：

- 页面头部只展示一次组件名称与用途，实时预览内部不重复标题和说明。
- 单横图、单竖图、两张、三张和更多图片五种布局直接铺开。
- 每种布局只保留状态名、状态值和尺寸说明，不使用折叠列表或属性控制卡。
- 示例之间只使用留白和分割线组织，不增加独立卡片背景。

## Props

```tsx
<DotsMediaImage
  images={[
    { src, alt, orientation: 'portrait | landscape' },
  ]}
  onMoreClick={openGallery}
/>
```

| 属性 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `images` | `DotsMediaImageItem[]` | 是 | 按内容顺序传入；空数组不渲染。 |
| `images[].src` | `string` | 是 | 业务图片地址。 |
| `images[].alt` | `string` | 是 | 图片内容描述；装饰图传空字符串。 |
| `images[].orientation` | `portrait / landscape` | 单图时是 | 由媒体元数据给出，组件不等待图片加载后猜测。 |
| `onMoreClick` | `() => void` | 否 | 超过三张时打开完整图片浏览器。 |

## 布局

| 场景 | 规格 |
|------|------|
| 单张竖图 | 165 × 220px，3:4 |
| 单张横图 | 219 × 164px，约 4:3 |
| 两张图片 | 每张占三列中的一列，第三列留空，不拉宽 |
| 三张图片 | 三列撑满 329px 内容宽度 |
| 多图单张 | `(容器宽度 - 12px) / 3`，3:4 |
| 多图间距 | 6px |
| 图片圆角 | 16px |
| 裁切 | `object-fit: cover` |

多图最多展示前三张。总数超过三张时，在图组下方 12px 处展示完整宽度的更多图片入口，文案为「N 张相关图片」，点击打开完整图片浏览器。

更多图片入口固定高 44px，水平 padding 0、垂直 padding 8px，内部间距 6px，背景使用 `Bg 0 Lighter`，圆角 40px。

## 状态

| 状态 | 行为 |
|------|------|
| `single-portrait` | 固定竖图尺寸。 |
| `single-landscape` | 固定横图尺寸。 |
| `group-two` | 使用三图单张尺寸，左对齐展示两张。 |
| `group-three` | 展示三张。 |
| `group-overflow` | 展示前三张和更多图片入口。 |

## 交互与触觉

- 点击图片：打开图片浏览器，触觉反馈 `light`。
- 点击更多图片入口：打开完整图片浏览器，触觉反馈 `light`。
- 图片和按钮内缩略图禁止拖动。
- 组件不自行维护当前浏览页、缩放或下载状态。

## Do / Don't

- Do：图片前后保留文字承接，说明图片为何出现在这里。
- Do：多图始终按输入顺序展示前三张。
- Do：使用真实 `alt`，让图片内容可被辅助技术理解。
- Don't：两张图时拉伸成两等分。
- Don't：把第四张叠在第三张上或使用 `+N` 遮罩。
- Don't：连续堆叠图片、图组、地图或商品卡。
- Don't：使用原图比例撑高多图内容流。

## 验收清单

- [ ] 单张横图为 219 × 164px。
- [ ] 单张竖图为 165 × 220px。
- [ ] 两张图和三张图使用相同单张尺寸。
- [ ] 多图比例 3:4，间距 6px，圆角 16px。
- [ ] 超过三张只展示前三张，并出现「N 张相关图片」入口。
- [ ] 更多图片入口撑满内容宽度并固定为 44px 高、40px 圆角。
- [ ] 图片使用 `object-fit: cover` 且不可拖动。
- [ ] 图片块前后存在文字承接。
